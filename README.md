# 🩺 AI Symptom Analyzer

An AI-powered web application that analyzes user-reported symptoms and provides possible medical conditions along with general health guidance. The application leverages Large Language Models (LLMs) to deliver intelligent symptom analysis while emphasizing that it is **not a substitute for professional medical advice**.

---

## 🚀 Features

- 🤖 AI-powered symptom analysis
- 📝 Natural language symptom input
- 💡 Possible condition suggestions
- 📋 General health recommendations
- ⚡ Fast and interactive web interface
- 🔒 Secure API key management using environment variables

- 🌍 **Multilingual Support**
  - Analyze symptoms in multiple languages (English and Hindi)

- 📄 **Medical Report Generation**
  - Generate downloadable PDF reports
  - Include reported symptoms, possible conditions, recommendations, and timestamp
  - Share reports with healthcare professionals

- 🎤 Voice symptom input
- 📷 Image-based symptom analysis (e.g., skin conditions)

🔐 User authentication and profile management
- 📚 Medical history tracking
- 💬 AI conversation history
